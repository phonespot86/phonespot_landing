# 씨티몰 시세 연동 아키텍처 (worker v8)

## 배경

- citymarket.co.kr 폐쇄 → 씨티몰(citymall.co.kr)의 새 백엔드 API로 전면 교체
- 씨티몰은 React SPA + 별도 API 서버 **qwe123.co.kr** (네트워크 분석으로 확인)
- GitHub Actions cron 방식은 과거에 불안정했음 → cron 없는 Worker 중계 구조 유지

## 구조

```
랜딩페이지 → Cloudflare Worker (중계 + 30분 캐시 + CORS) → qwe123.co.kr
```

**엔드포인트**
```
GET qwe123.co.kr/phone-price-lookup/products?carrierIdx={1|2|3}&sellChannelIdx=1
```
- carrierIdx: 1=KT, 2=SKT, 3=LG (4=알뜰폰)
- sellChannelIdx 1 = 폰스팟 (`/sell-channel/by-url?url=pb`로 확인)

**제품 필드**
- `modelPetName` ("갤럭시 S26_256G"), `modelPrice`(출고가), `pricePlanName`
- `calc{Public|Contract}{Port|New|Device}.purchasePrice`
  - Public=공시지원금 / Contract=선택약정, Port=번호이동 / New=신규 / Device=기기변경
- 노출 조건: `modelDisplayIsVisible == 1 && productDisplayIsVisiblePort == 1`

**워커 매핑**: 통신사별 `calcPublicPort`(번호이동+공시) 모델별 최저가
→ `{updated, models:[{name, deals:[{carrier, route, pct, price, original, plan, link}]}]}`

2026-08-10 기준 45개 모델 정상 응답.

## 캐시 정책

| 날짜 | 값 | 캐시키 |
|---|---|---|
| 초기 | 300초 | /v7 |
| ~08-10 | 6000초 | /v7 |
| 08-10 | 3600초 | /v7 |
| **현재** | **1800초 (30분)** | **/v8** |

`CACHE_SECONDS` 하나가 두 계층을 동시에 제어한다.

1. Cloudflare 엣지(`caches.default`) — 워커가 qwe123을 다시 조회하는 주기
2. 방문자 브라우저 — 응답의 `Cache-Control: public, max-age=N` ← **워커 호출 수를 줄이는 건 이쪽뿐**

⚠️ 두 계층이 겹치므로 표시 타임스탬프는 **최대 약 2×N**까지 과거일 수 있다 (30분 설정 → 최대 1시간).
⚠️ 값만 바꿔 배포하면 기존 엣지 캐시가 만료될 때까지 옛 정책이 유지된다. **`cacheKey` 버전도 함께 올릴 것.**

## Cloudflare 무료 플랜 (2026-08-10 확인)

요청 **100,000회/일**, 인보케이션당 CPU 10ms, 서브리퀘스트는 과금 대상 아님.

- 워커 내부 `caches.default` 히트도 **요청 1회로 집계**된다
  ("requests served from the Worker's cache are billed at the same per-request rate")
- 즉 내부 캐시는 qwe123 부하와 CPU만 줄이고, 트리거 횟수는 못 줄인다
- ❌ 폐기된 제안: "엣지 3600 / 브라우저 600 분리" — 워커 호출을 최대 6배 늘린다
- 실제 여유: 페이지뷰 약 12건/일 → 한도의 0.012%. 하루 10만 페이지뷰 전까지 요금 걱정 불필요

## 랜딩 쪽 연동 지점

1. **S1 가격 카드** — `PRICE_MODEL` 딜 3행 + 이미지 링크(최저가 딜)
2. **S4 최종 가격 카운트다운** — `갤럭시S26`/`아이폰17`로 시작하는 전 모델·전 통신사 중 최저가를 목표값으로,
   해당 딜의 출고가를 시작값으로 자동 설정
   - 캡션: `"{모델명} 최저가 · 오늘 HH:MM 업데이트"` (오늘이 아니면 `M월 D일 HH:MM`)
   - 구현: `window.__setS3Price(end, start, capText)` — `pRend=-1`로 래치 상태에서도 재렌더
   - 폴백(API 실패): -96,000원 + "오늘 기준 갤럭시 S26 최저가"
3. (예시 파일) 캠페인 프리롤·히어로 실시세 — `window.__fillCampaignPrice(data)`

## 딥링크 불가 (중요)

씨티몰 상세(`/order-intake/apply`)는 URL이 아닌 React Router 내부 state로만 진입한다.
외부에서 직접 접속하면 "주문 정보가 없습니다". `/pb`도 URL 파라미터를 읽지 않는다(번들 분석 확인).

→ 모든 링크는 `citymall.co.kr/pb` + UTM으로만.
씨티몰 개발자에게 딥링크(`?productIdx=`) 또는 통신사 탭 파라미터(`?carrierIdx=`) 지원 문의 중.
**지원되면 워커의 `linkFor()` 한 줄만 고치면 된다.**
