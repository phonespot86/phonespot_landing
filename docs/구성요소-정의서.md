## S3 조건 장면 (w25) 내용

폰스팟의 실제 운영 기준을 반영한 것. 문구를 바꿀 때 사실관계 확인 필요.

| 흔한 조건 | 폰스팟 |
|---|---|
| 부가서비스 5~6개? | **최소한**만 |
| 제휴카드 포함 가격? | **미포함 가격** 그대로 |
| 36개월 이상 장기 할부? | 일시불 · **24개월** |

배경: 부가서비스 3개월 유지 자체는 나쁜 게 아니고, 폰스팟은 1~2개 선에서 끊는다.
제휴카드는 기본적으로 미포함 가격으로 안내한다. 36개월 할부는 나쁜 것이 맞고,
고객이 요청하지 않는 한 24개월을 넘기지 않는다.

**연출 이력**: 처음엔 3개를 순차 3블록으로 만들었다가 "이어지지 않고 이상하다"고 반려됨.
헤드라인을 유지한 채 **한 화면 리스트**로 다시 만든 것이 현재 버전.

## 스크롤 시스템

- **PC**: 네이티브 + sticky + 속도 제한기(1.15화면/s)
- **모바일**: 가상 스크롤 — `#vport`/`#vbody` transform, 핀 transform 에뮬레이션
  - 튜닝 상수 3개(엔진 상단): `MOB_SPEED` 3.0 화면/s(하향 상한) · `MOB_PROG` 1.6 진행률/s(연출 진행 상한) · `MOB_GLIDE` 1.8(관성 감쇠)
  - `MOB_PROG`는 프레임당이 아니라 **시간 기준**이라 60Hz·120Hz에서 같은 속도로 재생된다
  - 4장면 최소 통과 시간 약 5.2초 (이전 1.7화면/s일 땐 9.1초)
  - **재방문자(`REVISIT`)는 `MOB_SPEED`/`PC_SPEED`를 999로 올려 사실상 해제**, `MOB_PROG`도 4.0으로 완화
    - 판정: `localStorage.ps_seen` 유무. 만료 없음. 저장 실패 시 첫 방문 취급
    - `?fast=1` / `?fast=0`으로 강제 지정 가능 (실기기 확인용, 플래그는 건드리지 않음)
    - 현재 GA4로 첫 방문/재방문을 구분해 보내지는 않는다 — 효과 측정하려면 별도 작업 필요
- **핀 길이**: PC 300 / 220 / 240 / 320svh + 클로징 · 터치 560 / 400 / 400 / 560svh (실측)
- 완료 섹션 래치 + 접힘(w25는 100svh로), 화면 근처 장면만 렌더
